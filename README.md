# Animals Sighting Dashboard

## Authors 
Daniel Balasingam

## Introduction

This is a simple ReactTS SPA web application, using a PHP+SQLite backend. 

The purpose of this project is to create an NZ animal sightings dashboard allowing users to record, track, and update animal sightings of a pre-defined list of species. 

## How to Run

First ensure code is downloaded or cloned, in a terminal navigate to the root directory of this project. 

Then run the run.sh file `./run.sh` in the terminal (you may need to make this file and executable with the `chmod +x ./run.sh`).

This will start the server (api) along with the react SPA.
